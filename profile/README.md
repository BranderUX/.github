# BranderUX

**Build agentic applications, in minutes. One message in. Your full agentic
application out: website and MCP app, live.**

App builders generate an app once — a design-time artifact, the same for
everyone. A BranderUX application is generated at runtime: every answer renders
as the right screen for the user's question, in your brand, and every click
becomes the next question. Your agent keeps the reasoning; BranderUX renders
the application.

## Start here

- 🌐 [branderux.com](https://branderux.com) — the platform
- 📚 [Docs](https://branderux.com/docs) — quickstart, API, examples
- 📦 [`@brander/sdk`](https://www.npmjs.com/package/@brander/sdk) — one React component, ~3-minute integration
- 🔌 [BranderUX MCP](https://branderux.com/mcp) — build on BranderUX from Claude, ChatGPT, Cursor or any MCP client

## See it live

- 🛍️ [Atelier Nova](https://nova.branderux.app) — a storefront with no pages: every screen generated at runtime ([source](https://github.com/BranderUX/atelier-nova))
- 🖥️ [MCP demo](https://github.com/BranderUX/mcp-demo) — branded UI rendering inside AI chat via MCP Apps
